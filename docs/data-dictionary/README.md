# Data dictionaries

A committed, machine-readable schema snapshot for every dataset this project
consumes, at `<source>/<dataset>.yaml`.

## The rule

**Read the YAML. Never read the raw file.**

Raw inputs here run from 100k-row ONS CSVs to multi-GB BDGD geodatabases and
fixed-width Fortran decks. Loading one into a working session burns the context that
should have gone into the actual work. The dictionary is ~2 KB and says everything a
session needs to write correct code against the data.

Generated by `scripts/_inspect.py`, which samples the raw file. Written once, in the
connector PR for that source. Regenerate — do not hand-edit — when upstream changes;
the diff is then a visible record of that change.

## Schema

```yaml
dataset: carga_energia_verificada
source: ons
source_url: https://dados.ons.org.br/dataset/carga-energia-verificada
retrieved: 2026-08-13T10:22:04Z
format: csv
encoding: utf-8
delimiter: ";"
decimal: "."
row_count: 4218960
schema_hash: sha256:1f3a…            # changes when columns/dtypes change

columns:
  - name: din_instante
    dtype: datetime64[ns]
    unit: null
    nullable: false
    description: Half-hourly timestamp, local Brasília time (UTC-3, no DST).
    sample: ["2024-01-01 00:00:00", "2024-01-01 00:30:00"]
  - name: val_cargaenergiamwmed
    dtype: float64
    unit: MWmed
    nullable: true
    null_rate: 0.0004
    description: Verified load, average MW over the half-hour interval.
    sample: [41823.7, 41102.4]

notes:
  - MWmed is average power over the interval, not energy. Multiply by interval
    hours for MWh.
  - Timestamps are Brasília local time; Brazil abolished DST in 2019, so no
    ambiguous hours after that. Earlier years DO contain them.
```

## Fields that matter most

`unit` and `notes` carry the information that causes real bugs. Brazilian sector data
mixes MW, MWmed, MWh and % of useful volume freely, and the distinction is rarely in
the column name. Fill these in properly even though the generator cannot infer them —
this is the one part a human or agent must write by hand after inspection.
