# ADR-0001 — Repository conventions

- **Status:** Accepted
- **Date:** 2026-08-13
- **Supersedes:** —
- **Superseded by:** —

## Context

This project is built largely through agent-assisted sessions with finite context
windows, over a long horizon (~43 planned pull requests across 10 epics), against
data sources that change upstream without notice. Three failure modes follow from
that and need structural defences rather than good intentions:

1. **Context exhaustion.** A session spends its window re-discovering schemas it
   already learned in an earlier session, then produces a truncated PR.
2. **Silent provenance loss.** Six months on, nobody can say which vintage of ONS
   data produced a published figure.
3. **Undocumented judgement calls.** Choices like bus-level load allocation or
   impedance synthesis get buried in code and cannot be defended in review or in a
   paper.

## Decision

### Commits and history

- **Conventional Commits** (`feat:`, `fix:`, `data:`, `docs:`, `chore:`,
  `refactor:`, `test:`), enforced by a `commitizen` commit-msg hook.
- **Squash-merge only**, linear history, `main` protected. One PR becomes exactly
  one commit on `main`, so `git log --oneline` is a readable project narrative — and
  cheap for a future session to load.

### Four-layer change log

| Layer | Artifact | Answers |
|-------|----------|---------|
| L1 | Conventional Commits | what changed, mechanically |
| L2 | `CHANGELOG.md` | what changed, for a human |
| L3 | `resources/_provenance/**.json` (committed) | which upstream data produced this |
| L4 | `docs/decisions/ADR-*.md` | why we chose this over the alternative |

Plus `results/<run_id>/manifest.json` per solve: config hash, git SHA, solver and
version, input provenance hashes, objective value, runtime.

### Per-PR session budget

A pull request must fit one working session. Limits:

| Dimension | Limit |
|-----------|-------|
| Files changed | ≤ 12 (excluding lockfiles and fixtures) |
| Net new Python | ≤ ~600 lines |
| Conceptual concerns | exactly 1 |
| New dependencies | ≤ 3 |
| Raw data read into context | never — use `scripts/_inspect.py` |

Sizes are `S` (≈⅓ session) and `M` (≈1 session). **`L` is not a shippable size**:
anything estimated `L` is split before work begins.

**Abort rule.** A session that reaches roughly 60% context before implementation is
complete stops, commits work-in-progress to the branch, writes its handoff note, and
opens a follow-up issue. Pushing through produces the worst kind of PR — one that
looks finished and is not.

### Context compression

Two artifacts exist purely so later sessions start cheap:

- **`docs/data-dictionary/<source>/<dataset>.yaml`** — a ~2 KB schema snapshot
  (columns, dtypes, units, null rates, sample values, source URL) generated by
  `scripts/_inspect.py`. Written once, in the connector PR. Every later session
  reads the YAML; nobody re-reads a 200 MB CSV or a multi-GB geodatabase.
- **`docs/handoffs/PR-NN.md`** — 20–40 lines committed with each PR: what landed,
  what the next PR needs, gotchas and dead ends. A minute to write, a session saved.

### Licensing

REUSE-compliant. MIT for code, CC-BY-4.0 for documentation, ODbL-1.0 for
OpenStreetMap-derived artifacts, which are confined to a marked output path so the
copyleft boundary stays auditable (see ADR-0002).

## Consequences

**Positive.** Sessions start with cheap, accurate context. Upstream schema drift
shows up as a git diff rather than a silent wrong number. Judgement calls are
defensible. `main` reads as a narrative.

**Negative.** Real overhead per PR — a changelog entry, a handoff note, sometimes an
ADR. Accepted deliberately: the alternative is re-deriving lost context, which costs
far more. The 12-file limit will occasionally feel artificial and force a split that
a human author would not have made; that is the intended trade.

**Risk.** Discipline decays under deadline pressure. Mitigated by making the checks
mechanical — CI enforces the changelog entry, provenance schema validity and ADR
numbering, so slippage fails the build rather than passing quietly.
