# PR-48 — Last month's inflow as an SDDP state (ADR-0011): built, not adopted

**Landed:**

- `scripts/prepare_sddp_inflow_state.py` — levels PAR(1) fit
  (`fit_levels_par1`), moments-matched three-parameter lognormal noise
  (`lognormal3_by_moments`, `standard_noise`, `sample_noise`), the December 2025
  starting inflow, `recover_noise` (the noise that reproduces each scoring
  path exactly) and `validate_levels_model`, which writes ADR-0011's table to
  `resources/sddp_inflow_state/levels_validation.json`.
- `julia/sddp_inflow_state.jl` — linear 12-stage graph, storage and last
  inflow as states, deficit slack at twice the load-shed cost. Includes
  `sddp_first_policy.jl` for shared constants and helpers.
- `julia/sddp_first_policy.jl` — `main()` guarded so it can be included.
- `scripts/check_sddp_inflow_state.py` — ADR-0011's acceptance test (P10 vs
  P90 own last inflow, others at mean; S deficit share at most 1%).
- `rules/sddp.smk` — `prepare_sddp_inflow_state`, `sddp_inflow_state_policy`,
  `check_sddp_inflow_state`.
- Tests: 12 in `test_prepare_sddp_inflow_state.py`, 6 in
  `test_check_sddp_inflow_state.py`.

## Result

| | ADR-0010 regional | ADR-0011 inflow state |
|---|---|---|
| cost on 1000 PAR(1) paths | R$233.78bn | R$233.76bn |
| acceptance test | fails (SE_CO) | **fails** (dry = wet everywhere) |
| grid backwards / tied | 14% / 4% | 0.6% / 59% |
| S deficit share | — | 0.98% (limit 1%) |
| serial training | 2 h 31 | 13 min |

Same cost, failed test, so by the project owner's rule the regional policy
stays. At the reference point the same cut is active after a dry and a wet
month: memory changes the level of future cost, not its slope in storage.

## What was learned

- **ADR-0009's negative-inflow rates do not reproduce.** A standard levels
  PAR(1) gives N 1.2-1.5% negative months, not 19.3%. S (3.6%) is the real
  problem. The table is now generated by code.
- **NEWAVE's structure, checked:** levels PAR(p), past inflows as states,
  three-parameter lognormal residuals with a state-dependent floor that makes
  it strictly nonlinear; cuts use the linear slopes (ADR-0011 sources).
- **13 minutes for 4000 iterations.** A 12-node graph with 8 states is far
  cheaper than 324 nodes with 4.

## Gotchas

- In-sample cost includes the deficit penalty; the scoring paths are always
  positive, so their cost has none.
- Recovered scoring noise has heavier tails than the training noise (S from
  -12 to +21) because the paths are log-PAR(1). Scoring fixes them; nothing
  requires them in the support.
- `check_sddp_inflow_state` failing is its verdict; the rule's failure is
  expected until the test passes.
